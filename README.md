# 토정비결 사주 대시보드

생년월일시를 입력하면 사주팔자 원국, 오행·십성 분포, 대운, 올해의 토정비결 괘와 월별 운세, 분야별 점수를 한 화면에서 보여주는 정적 웹 페이지입니다.

- 서버 없이 `index.html` 만 열면 동작합니다 (만세력: lunar-javascript, CDN).
- 입력한 정보는 서버로 전송되지 않으며, 저장 기능은 브라우저 localStorage 만 사용합니다.
- 토정비결 괘는 나이·생월·생일과 간지 수를 이용한 간이 계산이고, 풀이 문구는 자체 작성한 참고용 해석입니다.
- 전통 문화·오락 콘텐츠이므로 중요한 결정의 근거로 쓰지 마세요.

## 파일
- `index.html`, `style.css`, `app.js`: 화면
- `engine.js`: 사주·토정비결 계산 (브라우저/Node 공용)
- `proposal.html`: 초기 제안서
