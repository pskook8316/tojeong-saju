5. 기술 구성

  • 단일 HTML 파일, 서버 불필요. 노트북과 휴대폰 브라우저에서 모두 동작
  • 만세력 계산은 JS 라이브러리(예: lunar-javascript) 사용
  • 풀이 문구는 규칙 기반 텍스트로 시작, 이후 Claude API로 맞춤 문장 생성 확장 가능
  • 선택 기능: 결과 이미지 저장, 가족·지인 여러 명 저장

토정비결과 사주는 전통 문화·오락 콘텐츠이므로 화면 하단에 참고용 안내 문구를 넣습니다.
